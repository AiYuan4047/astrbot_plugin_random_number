# AstrBot 随机数生成插件

一个功能丰富的随机数生成插件，支持自定义范围、批量生成和群成员抽奖功能。

## 功能

### 1. 随机数生成
命令：`随机数 [数量] [最小值] [最大值]`

**特殊字符支持**：最小值或最大值位置可使用 `-` `_` `/` `#` `*` 表示使用配置文件中的默认值。

**示例**：
- `随机数` - 生成1个 1~100 的随机数
- `随机数 5` - 生成5个 1~100 的随机数
- `随机数 3 10 50` - 生成3个 10~50 的随机数
- `随机数 5 - 50` - 生成5个 1~50 的随机数（最小值使用默认值1）
- `随机数 3 10 *` - 生成3个 10~100 的随机数（最大值使用默认值100）

### 2. 掷骰子
命令：`掷骰子 [面数]`

**示例**：
- `掷骰子` - 掷一个6面骰子
- `掷骰子 20` - 掷一个20面骰子

### 3. 群成员抽奖
命令：`/成员抽奖 [人数] [y/n]`

- 第二个参数：`y` 排除管理员和群主（默认），`n` 不排除
- 只能在群聊中使用

**示例**：
- `/成员抽奖` - 抽取1人，排除管理员和群主
- `/成员抽奖 3` - 抽取3人，排除管理员和群主
- `/成员抽奖 2 n` - 抽取2人，包含所有成员

## 配置

编辑 `config.json` 文件可以自定义默认值：

```json
{
    "default_min": 1,
    "default_max": 100,
    "default_count": 1,
    "max_count": 100,
    "lottery_default_count": 1,
    "lottery_exclude_admin": true
}
```

**配置项说明**：
- `default_min`: 随机数默认最小值
- `default_max`: 随机数默认最大值
- `default_count`: 随机数默认生成数量
- `max_count`: 随机数最大生成数量限制
- `lottery_default_count`: 抽奖默认人数
- `lottery_exclude_admin`: 抽奖是否默认排除管理员和群主

## 安装

将插件解压到 AstrBot 的 `data/plugins/` 目录下即可使用。
