# AstrBot 随机数生成插件

一个功能丰富的随机数生成插件，支持自定义范围、批量生成、抛硬币和群成员抽奖，带 WebUI 管理面板。

## 功能

### 1. 随机数生成
命令：`/随机数 [数量] [最小值] [最大值]`

**特殊字符支持**：最小值或最大值位置可使用 `-` `_` `/` `#` `*` 表示使用配置文件中的默认值。

### 2. 抛硬币
命令：`/抛硬币`

- 正面概率 49.5%，反面概率 49.5%
- 极小概率（1%）硬币会立起来不倒，触发特殊彩蛋提示

### 3. 群成员抽奖
命令：`/成员抽奖 [人数] [y/n]`

- 第二个参数：`y` 排除管理员和群主（默认），`n` 不排除
- 只能在群聊中使用

## 配置

所有配置均可在 AstrBot WebUI 的插件管理页面直接进行面板配置，无需手动编辑文件。

**配置项**：
- `default_min`: 默认最小值（默认 1）
- `default_max`: 默认最大值（默认 100）
- `default_count`: 默认生成数量（默认 1）
- `max_count`: 最大生成数量限制（默认 100）
- `lottery_default_count`: 抽奖默认人数（默认 1）
- `lottery_exclude_admin`: 抽奖是否默认排除管理员和群主（默认 开启）
- `store_history`: 是否存储使用记录（默认 开启）
- `history_retention_days`: 历史记录保留天数（默认 30，0为永久保留）

## WebUI 管理面板

插件自带 WebUI 管理面板，可在 AstrBot WebUI 的插件管理页面点击「查看页面」打开。

**面板功能**：
- 顶部统计栏显示三个板块（随机数、抛硬币、成员抽奖）的使用总次数
- 横版筛选卡片栏，点击切换不同模块的记录
- 使用记录列表，支持按板块筛选
- 点击记录可查看详情，包括用户请求内容、生成结果、来源群、时间等
- 支持删除单条记录和清空所有记录
- 每5秒自动刷新数据

**注意**：面板仅显示 QQ 平台（NapCat 和 QQ开放平台Bot）的使用记录，其他平台的数据不会被存储和显示。

## 支持平台

本插件兼容以下 AstrBot 适配器平台：

| 平台 | 适配器 | 说明 |
|------|--------|------|
| QQ | NapCat | 个人QQ账号 |
| QQ | QQ开放平台Bot | QQ官方机器人 |
| 微信 | 微信龙虾（gewechat） | 微信个人号 |
| 微信 | 微信个人号 | 微信个人账号 |
| 微信 | 企业微信（wecom） | 企业微信机器人 |
| Telegram | Telegram Bot | 纸飞机机器人 |
| 飞书 | 飞书开放平台Bot | 飞书机器人 |

所有命令和功能在上述平台上均可正常使用。

**WebUI 面板数据存储**：
- 仅 QQ 平台（NapCat、QQ开放平台Bot）的使用记录会被存储并在 WebUI 面板中显示
- 其他平台（微信、Telegram、飞书）的使用记录不会被存储，也不会在面板中显示

## 安装

将插件解压到 AstrBot 的 `data/plugins/` 目录下即可使用。
